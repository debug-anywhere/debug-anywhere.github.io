隱私政策

更新日期：2026年10月23日

本政策說明 Debug Anywhere 行動應用及相關服務的資料處理方式。官網及您主動存取的服務也可能依下述方式處理技術資料。

1. 已儲存的除錯資料

指令碼、環境、User-Agent、請求標頭、瀏覽歷史、Cookie 和網頁儲存資料保存在您的裝置上。AsyncStorage 是本機儲存元件，不是當機資料收集服務。造訪網站、執行指令碼或傳送請求時，相關資訊可能傳送至您選擇的目標。本機儲存不代表應用程式的所有活動都不連網。

2. 使用統計、診斷及網路資訊

我們使用 Google Analytics for Firebase 了解頁面瀏覽、功能操作及應用使用情況。Firebase Crashlytics 處理當機報告、診斷記錄、呼叫堆疊，以及應用、安裝實例、裝置與系統資訊，以調查穩定性問題。這些服務可能處理識別碼及網路技術資訊。

應用會請求 https://httpbin.org/ip 取得公用 IP，該服務會接收請求及其網路資訊。應用也會將公用 IP 寫入部分廣告相關統計事件及 Crashlytics 診斷記錄，因此這些資料並非僅儲存在本機。

3. 廣告與追蹤選擇

免費版可透過 Google AdMob / Google Mobile Ads 顯示廣告。該 SDK 可能處理 IP 位址及由其推斷的概略位置、裝置或廣告識別碼、廣告顯示與互動、診斷及效能資料，以提供廣告、成效衡量、統計及防詐欺。廣告識別碼的可用性受 iOS 權限控制。您可在 iOS 設定中管理追蹤權限；拒絕追蹤不會關閉全部統計、當機報告或網路請求。Pro 移除應用內廣告顯示，但不代表關閉使用統計或診斷。

4. 購買與訂閱驗證

Apple 處理購買並管理 App Store 訂閱。為驗證及恢復權益，應用可能向我們的驗證服務傳送 App Store 收據，再由服務端向 Apple 驗證。服務透過 Supabase 儲存產品及交易識別碼、購買與到期時間、環境、驗證狀態及收據等訂閱資訊。Netlify 託管驗證服務，並可能處理請求與服務記錄。這些處理用於權益驗證、訂閱記錄、問題調查及防濫用。我們不會取得您的 Apple 帳號密碼或完整銀行卡資料。清除本機訂閱快取不會取消訂閱，也不會刪除服務端交易記錄。

5. 遠端管理、匯入與備份

只有在您啟用遠端管理後，應用才啟動本機服務。同一網路中的瀏覽器使用顯示的位址、連接埠及 Sync Code 存取已儲存設定。本機連線使用 HTTP 而非加密 HTTPS，請使用可信任的網路，並在完成後關閉服務。設定會傳送至您授權的瀏覽器；啟用遠端管理不等於將全部設定上傳到我們的雲端。

匯入、匯出及 ZIP 備份可能包含指令碼、User-Agent、環境、請求標頭及您填入的敏感資訊。請保護匯出檔案及接收檔案的瀏覽器、裝置。瀏覽器下載或分享後的檔案不屬於應用本機儲存，解除安裝應用不會刪除這些檔案。

6. 權限、支援與官網

相機用於掃描 QR Code；相簿權限用於相關圖片及截圖操作。剪貼簿與分享操作會將您選擇的內容交給系統或目標應用。您可在 iOS 設定中管理權限。

應用診斷記錄儲存在本機，可由您匯出用於支援。您向我們傳送記錄、截圖或郵件時，我們會收到您選擇分享的內容。記錄可能包含網路位址、網址、設定資訊或交易診斷，分享前請先檢查。官網使用 Sentry 監測錯誤與效能，可能處理頁面及請求網址、瀏覽器和裝置詳細資料、診斷資訊；網站託管服務也會處理請求技術資訊。

7. 儲存、保留與您的選擇

您可在應用內刪除已儲存項目，或透過解除安裝移除本機應用資料。這不會刪除匯出檔案、相簿圖片、已傳送給第三方的資訊或服務端訂閱記錄。Apple 訂閱須透過 Apple 管理。您可以聯絡我們，申請了解、存取或刪除我們持有的資料；我們將依適用要求，以及訂閱支援、安全或法律義務所需的記錄處理申請。服務商的資料保留及處理方式以其政策為準，處理地點可能位於您所在國家或地區之外。

8. 聯絡方式與服務商資訊

隱私問題請聯絡 i@debug-anywhere.com。相關服務商包括 Apple、Google/Firebase/AdMob、Netlify、Supabase、Sentry 及 httpbin.org。下方連結提供其資料處理說明。本政策更新時會在此頁面公布並調整日期。
