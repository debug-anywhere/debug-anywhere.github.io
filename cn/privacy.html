隐私政策

更新日期：2026年10月23日

本政策说明 Debug Anywhere 移动应用及相关服务的数据处理方式。官网以及您主动访问的服务也可能按下述方式处理技术数据。

1. 已保存的调试数据

脚本、环境、User-Agent、请求头、访问历史、Cookie 和网页存储保存在您的设备上。AsyncStorage 是本地存储组件，不是崩溃数据收集服务。访问网站、执行脚本或发送请求时，相关信息可能传输到您选择的目标。本地保存不代表应用的所有活动均不联网。

2. 使用统计、诊断和网络信息

我们使用 Google Analytics for Firebase 了解页面访问、功能操作和应用使用情况。Firebase Crashlytics 处理崩溃报告、诊断日志、调用堆栈，以及应用、安装实例、设备和系统信息，用于排查稳定性问题。这些服务可能处理标识符及网络技术信息。

应用会请求 https://httpbin.org/ip 获取公网 IP，该服务会接收请求及其网络信息。应用还会将公网 IP 写入部分广告相关统计事件和 Crashlytics 诊断日志，因此这些数据并非仅保存在本地。

3. 广告与跟踪选择

免费版可通过 Google AdMob / Google Mobile Ads 展示广告。该 SDK 可能处理 IP 地址及由其推断的大致位置、设备或广告标识符、广告展示与互动、诊断和性能数据，用于广告、效果衡量、统计及防欺诈。广告标识符的可用性受 iOS 权限控制。您可在 iOS 设置中管理跟踪权限；拒绝跟踪并不关闭全部统计、崩溃报告或网络请求。Pro 去除应用内广告展示，但不代表关闭使用统计或诊断。

4. 购买与订阅校验

Apple 处理购买并管理 App Store 订阅。为了校验和恢复权益，应用可能向我们的校验服务发送 App Store 收据，由服务端向 Apple 验证。服务通过 Supabase 保存产品及交易标识符、购买与到期时间、环境、校验状态和收据等订阅信息。Netlify 托管校验服务，并可能处理请求和服务日志。这些处理用于权益校验、订阅记录、故障排查和防滥用。我们不会获得您的 Apple 账户密码或完整银行卡资料。清除本地订阅缓存不会取消订阅，也不会删除服务端交易记录。

5. 远程管理、导入与备份

仅在您启用远程管理后，应用才启动本地服务。同一网络中的浏览器使用显示的地址、端口和 Sync Code 访问已保存配置。本地连接使用 HTTP 而非加密 HTTPS，请使用可信网络，并在完成后关闭服务。配置会传输到您授权的浏览器；开启远程管理不等于将全部配置上传到我们的云端。

导入、导出和 ZIP 备份可能包含脚本、User-Agent、环境、请求头以及您填写的敏感信息。请保护导出文件和接收文件的浏览器、设备。浏览器下载或分享后的文件不属于应用本地存储，卸载应用不会将其删除。

6. 权限、支持与官网

相机用于二维码扫描；相册权限用于相关图片和截图操作。剪贴板和分享操作会将您选择的内容交给系统或目标应用。您可在 iOS 设置中管理权限。

应用诊断日志保存在本地，可由您导出用于支持。您向我们发送日志、截图或邮件时，我们会收到您选择分享的内容。日志可能包含网络地址、网址、配置信息或交易诊断，请在分享前检查。官网使用 Sentry 监测错误和性能，可能处理页面及请求网址、浏览器和设备详情、诊断信息；网站托管服务也会处理请求技术信息。

7. 保存、保留与您的选择

您可在应用内删除已保存项目，或通过卸载应用移除本地应用数据。此操作不会删除导出文件、相册图片、已发送给第三方的信息或服务端订阅记录。Apple 订阅须通过 Apple 管理。您可以联系我们，申请了解、访问或删除我们持有的数据；我们将结合适用要求，以及订阅支持、安全或法律义务所需的记录处理申请。服务商的数据保留和处理方式以其政策为准，处理地点可能位于您所在国家或地区之外。

8. 联系方式与服务商信息

隐私问题请联系 i@debug-anywhere.com。相关服务商包括 Apple、Google/Firebase/AdMob、Netlify、Supabase、Sentry 和 httpbin.org。下方链接提供其数据处理说明。本政策更新时会在此页面公布并调整日期。
